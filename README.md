# Анализ бюджета Социального фонда России (2023–2025)

## Описание
Анализ бюджетных данных Социального фонда России на основе официальных источников за 2023–2025 годы.

## Что сделано
- сбор и структурирование данных из открытых источников  
- подготовка данных к анализу  
- анализ доходов и расходов фонда  
- сравнение показателей по годам  
- выявление динамики и ключевых изменений  

## Инструменты
Python (pandas), SQL

## Результат
- получена структура бюджета фонда  
- выявлены изменения в доходах и расходах по годам  
- проведён сравнительный анализ бюджетных показателей
